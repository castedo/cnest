About
=====

The content on this website is written by [Castedo Ellerman](https://castedo.com/about).
It communicates his human thoughts and knowledge.
Use of AI/LLMs is limited to spell checking, grammar checking, and light copyediting,
specifically with <https://copyaid.it>.

The scripts in the `cnest` package have been developed, tested, and used since
early 2020.

The `cnest` package of tools was inspired by the initial Bash script precursor of
[Fedora Silverblue Toolbox](https://github.com/containers/toolbox).

The static HTML for this website is built with
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).
